คำถามที่พบบ่อย (FAQ)

การสร้างกลุ่มใหม่ จะต้องมีจำนวนคนครบตามที่กำหนดในแต่ละแคมเปญภายในเวลาที่กำหนด

+เข้าร่วม สามารถเข้ากลุ่มใดก็ได้ ไม่จำเป็นต้องสร้างกลุ่มใหม่เพื่อให้ครบจำนวนตามที่กำหนด (เปิดกลุ่มสำเร็จ)

การจองแบบกลุ่มคือการรวมตัวกันจองทัวร์หรือบริการเพื่อรับราคาพิเศษที่ถูกกว่าราคาปกติ โดยจะต้องมีจำนวนคนครบตามที่กำหนดภายในเวลาที่กำหนด

หากไม่สามารถรวมกลุ่มให้ครบตามจำนวนที่กำหนดภายในเวลาที่กำหนด กลุ่มจะถูกยกเลิกโดยอัตโนมัติ และเงินมัดจำจะถูกคืนเต็มจำนวนภายใน 7-14 วันทำการ

{% if campaign.allow_partial_payment %} สามารถจ่ายเงินมัดจำก่อนได้ จากนั้นจ่ายส่วนที่เหลือภายในวันที่กำหนด โดยรองรับการชำระผ่านบัตรเครดิต โอนเงิน หรือ QR Code {% else %} ต้องชำระเต็มจำนวนทันที โดยรองรับการชำระผ่านบัตรเครดิต โอนเงิน หรือ QR Code {% endif %}

ไม่จำเป็น! คุณสามารถเข้าร่วมกลุ่มที่มีอยู่แล้ว หรือสร้างกลุ่มใหม่แล้วแชร์ให้คนอื่นเข้าร่วมได้ ระบบจะช่วยจับคู่คนที่สนใจโปรแกรมเดียวกันให้โดยอัตโนมัติ

สามารถยกเลิกได้ก่อนกลุ่มจะครบ โดยจะได้รับเงินคืนเต็มจำนวน แต่หากกลุ่มครบและเกิดการจองแล้ว จะต้องดำเนินการตามเงื่อนไขการยกเลิกของแต่ละทัวร์
